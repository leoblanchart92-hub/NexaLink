Mode Propriétaire

Contrôlez le partage de connexion, générez des QR codes, gérez les invités et surveillez la consommation en temps réel.

Mode Invité

Scannez le QR code, connectez-vous instantanément et accédez à Internet via le tunnel sécurisé.

Comment installer ?

1

Téléchargez le fichier APK depuis GitHub Actions

2

Activez "Sources inconnues" dans les paramètres Android

3

Ouvrez le fichier APK et installez l'application

4

Lancez NexaLink et acceptez les permissions
